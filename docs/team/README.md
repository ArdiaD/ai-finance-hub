# Team photos

Drop a square photo here for each member, named exactly as in the `TEAM` list
in `docs/index.html` (the `photo:` field), e.g.:

  david-ardia.jpg   serge-darolles.jpg   laurent-charlin.jpg  ...

Square JPG/PNG, ~400×400px is plenty. Until a file is present, the card shows a
coloured initials avatar automatically. To add a profile link, fill the `link:`
field in the same list (personal page or LinkedIn).
